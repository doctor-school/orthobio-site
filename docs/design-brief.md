## 1. Цель, аудитория, тон

**Что это:** временный статичный информационный сайт VIII Конгресса ОРТОБИОЛОГИЯ-2027 («весна 2027, даты уточняются») + консолидированный архив конгрессов 2021–2026. Без регистрации, без личного кабинета, без форм — единственный CTA ведёт наружу (Telegram/email). Живёт до ноября 2026, затем переезд на платформу Doctor.School.

**Аудитория:** врачи РФ — травматологи-ортопеды, ревматологи, реабилитологи, хирурги, неврологи; научные сотрудники; фарм-партнёры. Люди читают с телефона между приёмами и с рабочего десктопа. Значительная часть трафика — по старым ссылкам в архив.

**Тон:** научный медицинский конгресс федерального уровня (оргкомитет — академики РАН, директора НМИЦ). Дизайн должен транслировать **доверие, спокойствие, профессионализм** — это прямо зафиксировано в брендбуке («Для медицинских учреждений используются спокойные и нейтральные цвета»). Никакого маркетингового шума, таймеров обратного отсчёта, попапов. Светлая тема, «медицинский белый», воздух, строгая типографика. Плотный контент (программа на 175 докладов) должен читаться как хорошо свёрстанный научный документ, а не как лендинг-простыня.

**Язык интерфейса и контента:** русский. RU-типографика (ёлочки, неразрывные пробелы, тире) применяется на уровне данных — дизайн должен предполагать корректные русские кавычки и длинные тире в макетах.

## 3. Инвентарь компонентов (выведен из реальных данных)

Формы данных — из `src/content/schemas.ts` (Zod). Контракт нулевых значений: неизвестный факт = `null` / пустой список, компонент обязан иметь состояние «нет данных». Все цифры ниже — из реальных YAML.

### 3.1. Hero-2027 (главная)

- Данные: название («VIII Конгресс ОРТОБИОЛОГИЯ 2027»), строка дат-заглушка («весна 2027, даты уточняются»), цель конгресса (2–3 абзаца), блок цифр (7 конгрессов · 4 зала · 100+ докладов · 22 экспонента).
- CTA-кнопка «Регистрация откроется в ноябре 2026 — узнать первым» — единственная конверсионная точка сайта, внешняя ссылка из конфига (`TODO(Антон)`). Одна, заметная, без дублирующих форм.
- Крайние случаи: дат/места нет и не будет до отдельного объявления — hero не должен выглядеть «сломанным» без конкретной даты; когда даты появятся, строка просто заменится.

### 3.2. Карточка года архива (хаб `/archive/`)

- Данные на карточку: год, номер конгресса (римская цифра: II…VII), title, dates («22-24 апреля 2021»), place (⚠️ есть ТОЛЬКО у 2026, у 2021–2025 = null), cover-фото (url + alt + width/height; интринсики до 5811×3874).
- 6 карточек, 2021–2026. ⚠️ Cover есть у 2021–2025, а у **2026 cover = null и фото 0** (фотоотчёт ещё не опубликован оператором) — текстовая карточка без обложки это боевое состояние САМОГО СВЕЖЕГО года с первого дня, а не гипотетический fallback. Дизайн обязан сделать её полноценным первичным вариантом, не «сломанной» версией фото-карточки.
- Полезно показывать «что внутри» (есть программа / фото / видео / тезисы) — наполненность лет очень разная (см. таблицу §3.10).

### 3.3. Сетка программы (страница года)

Самый тяжёлый компонент. Данные `program.sessions[]`:

- **2025: 41 сессия, 175 докладов, 2 дня × 4 зала («Зал 1»…«Зал 4»), 25 сессий со сносками. 2024: 34 сессии, 155 докладов, 3 зала, 14 сносок.**
- Сессия: title (до 142 символов), date (ISO, для группировки «день 1 / день 2»; может быть null), time (свободный текст «09:00–10:30», может быть null), hall (может быть null), moderators[] (до 5 имён), talks[], note (сноска).
- Доклад: title (**до 464 символов** — реальный кейс 2025: программный список вопросов круглого стола одной строкой) + speakers[] (0–12 имён, максимум — в 2024; бывает пусто).
- Сноски (note) — содержательно важны для врачей: «Сателлитный симпозиум при поддержке компании X, **не обеспечивается баллами НМО**». Визуально отличимы от названия сессии, но не спрятаны.
- Требования к дизайну: мобильный вид — вертикальный список, сгруппированный день → зал → сессии (никаких горизонтальных таблиц 4 залов на 360px); десктоп может позволить навигацию день/зал (якоря, колонки). Компонент обязан переварить 464-символьный заголовок доклада без переполнения (перенос, `overflow-wrap`).
- Вариант «программа = PDF»: 2026 имеет только `program.pdf` (+ у года может быть И pdf, И sessions). Нужен паттерн «скачать программу (PDF)».
- Программа = null у 2021–2023 (не сохранилась) → блок либо скрыт, либо «программа не сохранилась».

### 3.4. Фотогалерея (страница года)

- Данные `photos[]`: url (self-hosted S3), alt, **обязательные width/height** (интринсики огромные, до 5811×3874 — дизайн задаёт целевые размеры отображения, резервирование места против CLS — жёсткое правило).
- Объёмы: 3 фото (2021), 12 (2022), 4 (2023), 6 (2024), 12 (2025), **0 (2026 — фото ещё не опубликованы оператором)**. Сетка должна прилично выглядеть и с 3, и с 12; при 0 блок скрывается.
- Лайтбоксы/карусели с client-JS по умолчанию не делаем (см. §5) — либо чистая сетка, либо CSS-only решение.

### 3.5. Видео-встраивания (страница года)

- Данные `videos[]`: url + title (может быть null). **23 реальных видео: 20 YouTube + 3 Rutube** (2021: 3, 2022: 8, 2023: 5, 2024: 4, 2025: 3, 2026: 0).
- Дизайн: единая карточка-плеер для обоих хостов; предусмотреть фасад «клик → загрузка iframe» (YouTube в РФ деградирован — соединение медленное; страница не должна грузить 8 iframe сразу, как на странице 2022 года). Title может отсутствовать → generic подпись.

### 3.6. Тезисы / документы года

- Данные `theses`: pdf + title (2024: PDF без title; 2026: «VII Конгресс ОРТОБИОЛОГИЯ 2026. Сборник тезисов», 123 стр.). У остальных лет null → блок скрыт.
- Плюс `posters[]` (пока пусто у всех реальных лет; по ТЗ 4 постера-2026 приедут после конгресса) — карточки изображений или PDF.
- Паттерн: заметная «документная» карточка со значком PDF и подписью.

### 3.7. Партнёрские уровни

- Данные `partners[]`: name, tier, logo (⚠️ **у ВСЕХ реальных партнёров logo = null** — логотипы не спасены; карточки на запуске текстовые), url (может быть null → просто текст без ссылки).
- 7 уровней (порядок и русские подписи фиксированы в `PARTNER_TIER_LABELS`): Организаторы → Соорганизаторы → Стратегические партнёры → Генеральные партнёры → Партнёры → Партнёры выставки → Информационные партнёры.
- Объёмы: **2026 — 52 организации во всех 7 уровнях** (5+16+2+5+6+9+9); 2025 — 34 в 4 уровнях; 2021 — 3 в одном; у 2022/2023 — 0 (блок скрыт).
- Дизайн: иерархия уровней (стратегические крупнее/заметнее, инфопартнёры компактнее), текстовые карточки должны выглядеть законченно, а не как «логотип не загрузился»; когда логотипы появятся — те же карточки с картинкой.

### 3.8. Президиум/обращения и оргкомитет

- `greetings[]` (президиум): name + role + photo + text; все поля кроме имени бывают null. Реальный разброс: 2021 — 2 персоны, только имя+роль (без фото и текста); 2022 — 3 с фото; 2025 — 2 с фото; 2026 — 0. Текстов обращений в данных пока нет ни у кого (text = null). Дизайн: карточка персоны деградирует до «имя + роль» без фото.
- `committee[]` (оргкомитет): name + regalia. 2025 — 9 персон, 2026 — 12. **Регалии — длинные строки до 238 символов** («К.м.н., заведующий кафедрой травматологии и ортопедии Академии постдипломного образования ФГБУ ФНКЦ ФМБА России, Главный внештатный специалист…»). Без фото. Дизайн: список/карточки, где длинная регалия читаема и не рвёт сетку; regalia может быть null.

### 3.9. FAQ и честные заглушки

- FAQ: список Q&A (~8–10 после урезания регистрационных). Без client-JS аккордеонов — либо развёрнутый список, либо нативный `<details>`.

## 5. Технические ограничения дизайна (жёсткие)

1. **RF-доступность.** Аудитория — врачи РФ. Никаких внешних CDN: шрифты self-hosted (woff2 в репо), иконки инлайн-SVG, никаких fonts.googleapis.com / cdnjs / unpkg / Cloudflare-зависимых цепочек. Видео — единственное исключение (YouTube/Rutube embed, желательно по клику).
2. **Статика без client-JS по умолчанию.** Astro SSG; `client:*` острова — только когда интерактив реально необходим. Дизайн не должен требовать JS: никаких каруселей, JS-аккордеонов, параллаксов, анимаций по скроллу. Допустимо: CSS-состояния, нативный `<details>`.
3. **Mobile-first, единая лестница брейкпоинтов** (Tailwind v4): `sm 640 · md 768 · lg 1024 · xl 1280 · 2xl 1536`. Никаких ad-hoc px. Проверочные ширины: 360, 390, 768, 1024, 1280 — ноль горизонтального переполнения.
4. **Только Tailwind-токены** — без hardcoded hex в вёрстке и inline-style. Все цвета §4 заводятся токенами темы.
5. **Устойчивость макета к реальному контенту:** grid/flex-дорожки с текстом — `minmax(0,…)`; заголовки — `overflow-wrap: break-word`; никаких фиксированных ширин > 360px viewport; карточные сетки через `repeat(auto-fill, minmax(min(100%, floor), 1fr))`. Стресс-тест макета: заголовок доклада 464 символа, регалия 238 символов, 52 партнёра, 175 докладов.
6. **Интерактивные состояния обязательны:** видимые `:hover`, `:active`, `:focus-visible` у каждого интерактивного элемента (фокус — токен `--color-ring #6BB1F7`).
7. **Доступность:** axe без critical/serious; контраст текста AA (см. предупреждение §4.1); осмысленные alt (в данных есть, но бывают null → generic подпись года).
8. **Фото с фиксированными размерами:** width/height обязательны в данных и в вёрстке (no-CLS), lazy-load, оптимизация через `astro:assets`.
9. **152-ФЗ:** на сайте нет форм и сбора ПД — дизайн не должен их предлагать.

## 6. Чего НЕ делать

- **Не копировать вёрстку orthobio.ru** (движок конгресс-оператора) и **шаблоны creatium.site** (архив 2021–2025) — ТЗ прямо запрещает; это чужие продукты, к тому же с внутренними противоречиями. Разведка (`docs/recon/orthobio-ru-main.md`) — источник фактов, не референс дизайна.
- **Не выдавать контент-2026 за 2027:** ни дат, ни дедлайнов, ни программы 2026 на страницах 2027 — только честные заглушки со ссылкой в архив.
- Не изобретать факты под макет: нет фото года → блока нет; нет текста обращения → карточка без текста. Placeholder-lorem в макетах допустим только с пометкой, что в проде поле бывает null.
- Не тянуть внешние архивные ссылки (Drive/Яндекс.Диск/creatium/cdn оператора) — весь архив self-hosted.
- Не делать тёмную тему, регистрационные формы, таймеры, попапы, cookie-баннеры (кук нет).
- Не использовать Tactic Sans Extended / Century Gothic для текста (нет файлов/лицензий, §4.3).
