Самодостаточный исходник для визуального дизайна сайта (Claude.design) перед вёрсткой.

## 1. Цель, аудитория, тон

**Что это:** статичный информационный сайт VIII Конгресса ОРТОБИОЛОГИЯ-2027 («весна 2027, даты уточняются») + консолидированный архив конгрессов 2021–2026; весь архив (фото, PDF) хостится на нашей инфраструктуре. Без регистрации, без личного кабинета, без форм — единственный CTA («Регистрация откроется в ноябре 2026 — узнать первым») ведёт наружу, в Telegram/email.

**Аудитория:** врачи РФ — травматологи-ортопеды, ревматологи, реабилитологи, хирурги, неврологи; научные сотрудники; фарм-партнёры. Люди читают с телефона между приёмами и с рабочего десктопа. Значительная часть трафика — по старым ссылкам в архив.

**Тон:** научный медицинский конгресс федерального уровня (оргкомитет — академики РАН, директора НМИЦ). Дизайн транслирует **доверие, спокойствие, профессионализм**: сдержанная информационная подача, светлая тема, «медицинский белый», воздух, строгая типографика. Плотный контент (программа на 175 докладов) должен читаться как хорошо свёрстанный научный документ, а не как лендинг-простыня.

**Язык:** русский, с корректной RU-типографикой в макетах — «ёлочки», длинные тире, неразрывные пробелы.

## 3. Инвентарь компонентов (из реальных данных)

Контракт нулевых значений: неизвестный факт = `null` / пустой список, у каждого компонента есть состояние «нет данных».

### 3.1. Hero-2027 (главная)

- Данные: название («VIII Конгресс ОРТОБИОЛОГИЯ 2027»), строка дат-заглушка («весна 2027, даты уточняются»), цель конгресса (2–3 абзаца), блок цифр (7 конгрессов · 4 зала · 100+ докладов · 22 экспонента).
- CTA-кнопка — единственная конверсионная точка сайта, внешняя ссылка из конфига (`TODO(Антон)`). Одна, заметная.
- Крайний случай: конкретных дат/места нет до отдельного объявления — hero не должен выглядеть «сломанным» без них; когда даты появятся, строка просто заменится.

### 3.2. Карточка года архива (хаб `/archive/`)

- Данные на карточку: год, номер конгресса (римская цифра: II…VII), title, dates («22-24 апреля 2021»), place (есть ТОЛЬКО у 2026, у 2021–2025 = null), cover-фото (url + alt + width/height; интринсики до 5811×3874).
- 6 карточек, 2021–2026. ⚠️ Cover есть у 2021–2025, а у **2026 cover = null и фото 0** (фотоотчёт ещё не опубликован) — текстовая карточка без обложки это боевое состояние САМОГО СВЕЖЕГО года с первого дня. Дизайн обязан сделать её полноценным первичным вариантом, не «сломанной» версией фото-карточки.
- Полезно показывать «что внутри» (есть программа / фото / видео / тезисы) — наполненность лет очень разная (см. таблицу §3.10).

### 3.3. Сетка программы (страница года)

Самый тяжёлый компонент.

- **2025: 41 сессия, 175 докладов, 2 дня × 4 зала («Зал 1»…«Зал 4»), 25 сессий со сносками. 2024: 34 сессии, 155 докладов, 3 зала, 14 сносок.**
- Сессия: title (до 142 символов), date (для группировки «день 1 / день 2»; может быть null), time (свободный текст «09:00–10:30», может быть null), hall (может быть null), moderators[] (до 5 имён), talks[], note (сноска).
- Доклад: title (**до 464 символов** — реальный кейс: программный список вопросов круглого стола одной строкой) + speakers[] (0–12 имён; бывает пусто).
- Сноски (note) содержательно важны для врачей: «Сателлитный симпозиум при поддержке компании X, **не обеспечивается баллами НМО**». Визуально отличимы от названия сессии, но не спрятаны.
- Мобильный вид — вертикальный список, сгруппированный день → зал → сессии (горизонтальная таблица 4 залов на 360px невозможна); десктоп может позволить навигацию день/зал (якоря, колонки). Компонент обязан переварить 464-символьный заголовок без переполнения.
- Вариант «программа = PDF»: у 2026 только PDF (у года может быть и PDF, и структурированные сессии) — нужен паттерн «скачать программу (PDF)».
- Программа = null у 2021–2023 (не сохранилась) → блок скрыт или «программа не сохранилась».

### 3.4. Фотогалерея (страница года)

- Данные `photos[]`: url, alt, обязательные width/height (интринсики до 5811×3874; дизайн задаёт целевые размеры отображения, место под фото резервируется заранее).
- Объёмы: 3 фото (2021), 12 (2022), 4 (2023), 6 (2024), 12 (2025), 0 (2026). Сетка должна прилично выглядеть и с 3, и с 12; при 0 блок скрывается.
- Без client-JS лайтбоксов/каруселей (§5) — чистая сетка или CSS-only решение.

### 3.5. Видео-встраивания (страница года)

- Данные `videos[]`: url + title (может быть null → generic подпись). **23 реальных видео: 20 YouTube + 3 Rutube** (2021: 3, 2022: 8, 2023: 5, 2024: 4, 2025: 3, 2026: 0).

### 3.6. Тезисы / документы года

- `theses`: PDF + title (2024: PDF без title; 2026: «VII Конгресс ОРТОБИОЛОГИЯ 2026. Сборник тезисов», 123 стр.). У остальных лет null → блок скрыт.

- Паттерн: заметная «документная» карточка со значком PDF и подписью.

### 3.7. Партнёрские уровни

- Данные `partners[]`: name, tier, logo (⚠️ у ВСЕХ реальных партнёров logo = null — карточки на запуске текстовые), url (может быть null → текст без ссылки).

- Иерархия уровней (стратегические крупнее/заметнее, инфопартнёры компактнее); текстовые карточки должны выглядеть законченно, а не как «логотип не загрузился»; когда логотипы появятся — те же карточки с картинкой.

### 3.8. Президиум/обращения и оргкомитет

- `greetings[]` (президиум): name + role + photo + text; все поля кроме имени бывают null. Разброс: 2021 — 2 персоны, только имя+роль; 2022 — 3 с фото; 2025 — 2 с фото; 2026 — 0. Текстов обращений нет ни у кого (text = null). Карточка персоны деградирует до «имя + роль» без фото.

Длинная регалия читаема и не рвёт сетку; regalia может быть null.

## 5. Технические ограничения дизайна (жёсткие)

1. **RF-доступность.** Аудитория — врачи РФ. Никаких внешних CDN: шрифты self-hosted (woff2 в репо), иконки инлайн-SVG, никаких fonts.googleapis.com / cdnjs / unpkg / Cloudflare-зависимых цепочек. Видео — единственное исключение (YouTube/Rutube embed, желательно по клику).
2. **Статика без client-JS по умолчанию.** Дизайн не должен требовать JS: никаких каруселей, JS-аккордеонов, параллаксов, анимаций по скроллу. Допустимо: CSS-состояния, нативный `<details>`.
3. **Mobile-first, единая лестница брейкпоинтов:** `sm 640 · md 768 · lg 1024 · xl 1280 · 2xl 1536`. Проверочные ширины: 360, 390, 768, 1024, 1280 — ноль горизонтального переполнения.
4. **Все цвета — токенами** дизайн-системы, без ad-hoc значений в макетах: каждая роль цвета должна быть именуемой.
5. **Устойчивость к реальному контенту:** сетки и заголовки обязаны переваривать стресс-кейсы — заголовок доклада 464 символа, регалии 238 символов, 52 партнёра, 175 докладов — без горизонтального скролла от 360px.
6. **Интерактивные состояния обязательны:** видимые `:hover`, `:active`, `:focus-visible` у каждого интерактивного элемента. Фокус-кольцо — двухцветное: 2px гало `#FFFFFF` вплотную к элементу + 2px кольцо `#114D9E` снаружи (issue #35; одноцветный `#6BB1F7` давал 2.27:1 на белом при пороге 3:1 по WCAG 2.2 SC 1.4.11).
7. **Доступность:** без критичных и серьёзных нарушений доступности; контраст текста AA (см. §4.1); осмысленные alt (бывают null → generic подпись года).
8. **Изображения с фиксированными размерами** (место резервируется заранее, без сдвигов макета при загрузке), lazy-load.
9. **152-ФЗ:** на сайте нет форм и сбора персональных данных.
